## 🚀 5-Minute Setup

### Step 1: Add Your API Key
1. Open the **Vault** tab
2. Find **Claude** or **OpenRouter**
3. Click **"Add Key"**
4. Paste your API key (e.g., `sk-ant-...`)
5. Click **"Save"**

🔒 **Your key is encrypted with AES-256-GCM** - never stored in plaintext.

### Step 2: Create Your First Episode
1. Open the **AI Soap Opera** tab
2. Enter an episode title: `"Shadows of Dubai"`

## 📖 Tutorial-Based Workflow

This system automates the workflow demonstrated in the video tutorials:

### **1. Script Generation** 📝
**What it does:**
- Creates dramatic 60-second scripts
- Includes compelling cliffhanger endings
- Perfect for episodic content

**Behind the scenes:**
```
ChatGPT Prompt: "Write a dramatic soap opera script
titled '[YOUR_TITLE]' with a cliffhanger ending."
```

### **2. Character Creation** 👥
**What it does:**
- Generates visual character descriptions
- Creates 9:16 aspect ratio character images
- Full-body shots for dynamic scenes

**Behind the scenes:**
```
ChatGPT Prompt: "Based on this script, describe 2-3
main characters visually for image generation."
```

### **3. Scene Prompts** 🎬
**What it does:**
- Creates Veo 3-ready video prompts
- Specifies "two angles and lips synced"
- One scene at a time for maximum detail

**Behind the scenes:**
```
ChatGPT Prompt: "Create Veo 3 prompts for each scene.
Specify 'two angles and lips synced'. One at a time."
```

### **4. Video Generation** 🎥
**What it does:**
- Ready-to-use prompts for Veo 3
- 16:9 landscape format (YouTube-optimized)
- Automatic lip-syncing enabled

**How to use:**
1. Copy the scene prompts from the app
2. Go to [Google Labs Veo 3](https://labs.google/veo)
3. Upload character images
4. Paste scene prompts
5. Set ratio to 16:9
6. Generate!

### **5. CapCut Editing** ✂️
**Editing checklist provided:**
- [ ] Import all generated scenes
- [ ] Arrange in sequence (no transitions)
- [ ] Add soap opera background music
- [ ] Add scene text: "Somewhere in Dubai at 4:35"
- [ ] Add cliffhanger text: "To Be Continued"
- [ ] Adjust music levels for drama
- [ ] Export final episode

## 🏆 Pro Tips for Viral Content

### From the Tutorials:
1. **💡 Cliffhanger Endings**
   - Every episode must end with a question
   - Leave viewers wanting more
   - Example: "But little did she know..."

2. **🎬 Two Camera Angles**
   - Request "two angles" in every prompt
   - Adds cinematic variety
   - Example: "Close-up + wide shot"

3. **🗣️ Lip Sync Specification**
   - Always specify "lips synced" in prompts
   - Critical for dialogue scenes
   - Veo 3 handles this automatically

4. **📐 Aspect Ratio Matters**
   - YouTube: 16:9 landscape
   - TikTok: 9:16 portrait
   - Character images: 9:16 for full-body

5. **🎵 Dramatic Music**
   - Add soap opera background music
   - Emphasize at reveal moments
   - Adjust levels for dialogue clarity

6. **⏱️ 60-90 Second Episodes**
   - Perfect length for binge-watching
   - Keeps engagement high
   - Easier to maintain quality

7. **📍 Consistent Location**
   - Set clear location (e.g., "Dubai")
   - Creates visual continuity
   - Easier for Veo 3 to generate

8. **✂️ No Transitions**
   - Direct cuts only
   - Maintains TV show feel
   - Faster editing process

## 🎬 Example Episode Structure

### "Shadows of Dubai - Episode 1"

**Script (60 seconds):**
```
Scene 1: Dubai penthouse, sunset
ALEX: "The deal is off."

Scene 2: Close-up, shocked expression
SARA: "But the contract—"

Scene 3: Wide shot, city skyline
ALEX: "There is no contract."

Scene 4: Two-shot, dramatic lighting
SARA: "Then everything we built..."

[CLIFFHANGER]
Scene 5: Door opens, mysterious figure
FIGURE: "Not everything."

TO BE CONTINUED...
```

**Characters:**
- Alex (30s businessman, sharp suit)
- Sara (20s entrepreneur, determined)
- Figure (mysterious, silhouette)

**Veo 3 Prompts:**
1. "Close-up of businessman in Dubai penthouse at sunset, serious expression, lips synced. Wide shot shows luxury interior with city skyline."

2. "Close-up of woman shocked expression, lips synced dialogue. Medium shot reveals full office setting."

3. "Two-shot of businessman and woman, dramatic side lighting, tense body language, lips synced. Wide angle captures entire penthouse."

4. "Silhouette of mysterious figure in doorway, backlit, dramatic entrance. Medium shot shows partial features."

## 🚀 5-Minute Quick Start

### 1️⃣ Get API Key
```
1. Go to: console.anthropic.com
2. Sign up → API Keys → Create Key
3. Copy: sk-ant-api03-XXXXXXXX
4. Save it somewhere safe!
```

### 2️⃣ Run the App
```
1. Open: your-app-url.vercel.app
2. Click: Vault tab
3. Add: Your API key
4. Click: Save
```

### 3️⃣ Create Episode
```
1. Click: AI Soap Opera tab
2. Enter: Episode title
3. Click: Auto-Generate Episode
4. Wait: ~45 seconds
5. Done!
```

## 🆘 Emergency Troubleshooting

### App Won't Start
```bash
npm install
npx kill-port 3000
npm start
```

### API Key Not Working
```
1. Check format: sk-ant-api03-...
2. Check billing in Anthropic console
3. Regenerate key if needed
```

### "Rate Limit" Error
```
1. Wait 60 seconds
2. Reduce batch size
3. Check API tier
```

### White Screen After Deploy
```
1. Open DevTools (F12)
2. Check Console for errors
3. Rebuild: npm run build
4. Clear browser cache
```

## 💡 Pro Tips (From Tutorials)

| Tip | Why | How |
|-----|-----|-----|
| **Cliffhangers** | Keep viewers hooked | End each episode with question |
| **Two Angles** | Cinematic variety | Specify in Veo prompts |
| **Lip Sync** | Natural dialogue | Always enable in Veo |
| **16:9 Format** | YouTube optimized | Best for series content |
| **No Transitions** | TV show feel | Direct cuts only |
| **60-90 seconds** | Binge-worthy | Perfect episode length |
